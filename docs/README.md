# OctoAcme Project Management Docs

A guide to how OctoAcme initiates, plans, delivers, releases, and learns from cross-functional projects.

## Project Management Processes Summary

OctoAcme uses a customer-first, iterative approach with clear ownership and data-informed decisions. The Project Manager coordinates delivery, schedules, risks, and communications; the Product Manager defines outcomes and prioritizes the backlog; developers and QA collaborate to build and validate changes; and stakeholders provide input and approvals. Projects move through initiation, planning, execution and tracking, release, and closeout with a retrospective. Teams maintain artifacts such as a project charter, roadmap, iteration backlog, acceptance criteria, risk register, and retrospective actions. The regular communication cadence includes weekly PM/PdM syncs, twice-weekly delivery standups (or as agreed), monthly stakeholder updates, and ad-hoc escalations.
